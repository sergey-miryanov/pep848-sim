Playground

Pick a workload to start from, then change any part of it. The legend beside the object graph edits each structure, the churn, the run and the constants no Python API changes: open a line with edit, change a field, and both collectors run the workload again. A structure can take a shape of your own: pick Your own, in Python and write the links each new object brings. The workload you pick keeps your changes while the page stays open.

To compute a size, loop over structures or keep your shapes in one place, switch Edit to as Python. You get the whole workload as Python: change it and press Run. Switch back, and the legend shows what your Python made.

After each run the address holds your workload, so a reload keeps it and Copy link gives you a link to send. A link with a shape of its own opens its Python and waits for you to read it and press Run.

The first runs wait a few seconds while Pyodide, the Python that runs in the browser, downloads and starts. The home page explains what the widget draws.
