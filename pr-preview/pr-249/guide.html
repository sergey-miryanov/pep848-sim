PEP 848 simulator Guide Playground GitHub

PEP 848 proposes a generational incremental cycle collector for CPython. This guide takes it a chapter at a time. Each step sets the widget to show one thing under both collectors, and its notes say where to look. Step with the arrows beside the chapter's name or the arrow keys. The first runs wait a few seconds while Pyodide, the Python that runs in the browser, downloads and starts.
